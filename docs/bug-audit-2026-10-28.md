# 原版部署缺陷排查与修复 · 2026-10-28

范围：当前实际使用的 `upstream/cyber-xiaoya-live`、本机适配、OBS 舞台页面及根目录启动器。
旧版平台的数据、密钥、形象、人设和配置保持原样。本轮没有创建 Vidu 视频会话，没有调用付费 LLM 测试。
服务适配版本更新为 `macos-2`。

## 已确认并修复

| 问题 | 可复现场景与影响 | 修复 |
|---|---|---|
| 取消后仍创建会话 | 余额检查等待期间点停止，原逻辑随后仍创建云端会话，再关闭 | 付费创建前复查取消标志；创建过程中显示“取消连线”按钮 |
| 任务取消未关闭信令 | 已取得云端会话 ID、WebSocket 连接过程中任务被取消，CancelledError 绕过 Exception 清理 | 启动异常清理覆盖取消，并继续向上抛出取消；执行挂断和关闭 |
| 初始化未成功却显示直播中 | conn_init 在连接关闭时返回 False，上游忽略返回值继续切到 live | 没有成功回执就报告初始化失败并清理 |
| 预算输入可破坏保护 | null、nan、负数和非整数时长可保存，使状态转换报错或预算比较失效 | 写入前和创建前校验时长、预算及估算费率；无效值返回 400；界面空时长默认恢复 120 秒而非 1800 秒 |
| OBS 重连竞态 | 上一场心跳迟到失败会关闭新连接；漏过两场之间 idle 状态时保留旧 RTC | 按会话和连接代次丢弃旧回调；检测会话 ID 变化并重新加入；清理旧帧回调 |
| TRTC 凭证与视频检测错误 | 自备 TRTC 错用 ARTC AppID；SDK 创建的视频不在原占位 video 上，误判无画面 | 使用 TRTC sdk_app_id；帧检测绑定实际有解码尺寸的视频元素 |
| OmniVoice 改地址未生效 | 已缓存 Gradio 客户端后更改地址，只改 cfg_base，旧客户端继续被复用 | 语音服务地址或超时设置变化时重建适配实例，丢弃旧客户端 |
| 大模型测试干扰对话 | 测试调用复用正式对话历史；测试与开播并发时可能恢复过期历史 | 测试使用独立 LLMClient 和空历史，并与启动共用互斥锁 |
| 设置音色刷新无响应 | 音色面板和设置面板使用相同按钮 ID，事件都绑定到第一个按钮 | 独立 ID，分别绑定各自刷新操作 |
| 受限环境误报服务停止 | localhost 访问被权限拒绝时，启动器把 PermissionError 当作端口未监听 | 区分拒绝访问、连接被拒绝与其他网络错误；状态未知时不尝试启动或终止进程 |

## 验证证据

先新增失败测试复现，再修复。关键后端回归新增后出现 9 个失败断言（含无效预算子用例），OBS 前端新增 4 项失败，启动器新增 1 项失败；另补初始化 False 的失败用例。

- 本机后端：20 项测试通过。所有云服务调用使用 mock，配置和账本位于临时目录。
- 前端适配：9 项测试通过，覆盖迟到心跳、跨场重连、真实媒体元素选择、取消入口和重复 ID。
- 启动器：3 项测试通过。
- 原版动作路由 T0：13/13；过滤漏斗：35/35；随机动作：8 项检查通过。
- 页面实际验收：设置里的音色刷新点击产生 1 次请求，返回 3 个音色；Key 为密码框且不回显，读取到已保存状态；未出现未处理异步异常。
- 空闲服务重启后保留原配置，单场 120 秒、预算 200 积分，服务报告 macos-2。
- 当前 macOS 语音实测生成 2.61 秒 WAV，24kHz、单声道、16 位；无需云端语音服务。
- 已打开 OBS，确认“原版小沐直播”场景未录制、未推流；刷新浏览器源后收到待机心跳，截图确认小沐待机图正常。
- 源码补丁重新导出，并在固定上游提交的干净快照中验证可应用。

## 验收边界

本轮覆盖离线回归、本机服务和页面行为。真实 Vidu 音画、口型、音轨、延迟、扣费与 OmniVoice 服务质量仍需短时真实试播，不能由这些测试代替。
TRTC 分支通过模拟凭证与媒体回调检查，没有真实 TRTC 账号入会验证；当前默认仍是托管 ARTC。
无法用本次检查保证整个上游仓库不存在其他缺陷。
