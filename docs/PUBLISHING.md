# 发布范围与密钥保护

本次发布使用独立的干净 Git 仓库，只有筛选后的源码和示例素材。没有复制开发工作区的 `.git`，因此旧本机提交、撤销记录与对象不会进入远端历史。

允许发布：Python / 前端源码、测试、安装与启动工具、示例配置、原创 starter 素材、许可证、上游适配补丁及校验清单。

排除发布：`.secrets/`、`.state/`、真实 `config.json` 及备份、`.env`、Cookie、推流码、OBS 密码、日志、录播、上传素材、个人音色、虚拟环境、下载的 SDK、上游克隆目录和整个本机旧 Git 历史。

发布前检查：

1. 文件名和路径排除规则；拒绝符号链接。
2. 常见 API Token / 私钥模式检查。
3. 在本机内存中读取本项目已经配置的凭据，只比较候选文件是否包含原文或常见编码形式；检测结果只记录文件和规则，不记录凭据值。
4. 提交后扫描全部 Git blob；发布后核对远端提交和文件树。

`.gitignore` 用于预防误提交，不能替代内容和 Git 历史扫描。后续推送前也应检查 `git diff --cached`，不要使用 `git add -f` 添加本机配置。

LLM Key 保存在 `.secrets/llm.key`，Vidu Key 按上游设计保存在本机配置中；这些文件应只在本机保管。仓库不需要真实 Key 即可进行离线回归。

如果将来误上传密钥，应先在服务商侧吊销 / 轮换，再处理仓库历史；仅删掉最新文件不足以移除旧提交中的凭据。
