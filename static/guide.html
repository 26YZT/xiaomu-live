你的第一场数字人直播

本地准备 → 演练 → 接入数字人 → 输出直播画面

现在就能使用

角色、人设、衣柜、素材上传、动作规则、弹幕过滤和排队都在本机运行。已准备原创角色“小沐”与深蓝、森林绿两套毛衣底图。

演练显示静态底图和模拟文字反馈，不生成语音或动态视频。真实数字人需要你自己的 Vidu API Key；尚未接入抖音真实弹幕。

开始演练

1. 先演练一轮

  1. 在直播间点击“演练一轮”。三条普通弹幕会进入队列，一条广告会被过滤。
  2. 点击“换上绿色毛衣”，观察队列执行后静态底图变化。默认演练每 5 秒处理一条。
  3. 查看执行记录与过滤记录。结束时点击“停止数字人”。设置页可以查看这次零费用会话。

2. 准备自己的角色

  1. 在“素材”上传一张清晰的单人形象图，然后在“角色”新建角色，或把素材设为现有角色的底图。
  2. 编辑人设、开场白和暖场话题。声音页可选系统音色；克隆声音需要服务连接和你有权使用的音频。
  3. 每套衣服提前准备一张完整角色图，加入衣柜并设置好名字和别名。保持人物、背景、光线和构图一致。

示例角色图片由本次搭建生成，尚未经过 Vidu 的动态效果验证。请先私下短时测试再公开直播。

3. 连接 Vidu

  1. 去 Vidu 开放平台申请你自己的 API Key，并确认账号可使用实时数字人。
  2. 回“设置 → 连接服务”，选择 Vidu，粘贴 vda_ 开头的 Key，保存并点击“验证 Vidu”。验证只查询音色，不创建数字人会话。
  3. 先设置单场与今日预算，再回直播间点击“启动数字人”。保持预览或 OBS 浏览器源打开。

参考标准单价为 1.5 积分/秒、0.03125 元/积分，约 ¥168.75/小时；以你自己的账户报价和账单为准。默认单场最多 10 分钟、900 积分，今日预算 3200 积分。费用每秒检查，停止信令与网络可能造成少量超出。

自动恢复默认关闭。开启后会继续产生费用；今日累计预算跨重启保存。异常退出的会话费用需回 Vidu 控制台核对。

4. 通过 OBS 输出

  1. 安装 OBS，工作台“推流”页选择“用 OBS”。按页面给出的地址添加浏览器源。
  2. 需要自动创建场景时，在 OBS 启用 WebSocket 服务，将密码保存到工作台“设置 → OBS WebSocket”。
  3. 在项目目录运行下方命令创建横屏场景；命令会配置 OBS 场景和画布，但不会开始公开推流。
.venv/bin/python tools/obs_control.py setup douyin

通过 OBS 虚拟摄像头或投影窗口，将画面交给抖音直播伴侣。虚拟摄像头不带声音，需要在直播伴侣中单独配置音频采集。开播前确认预览画面和音频电平。

停止数字人只结束数字人会话；OBS 和直播伴侣的公开直播需分别停止。

5. 接入真实弹幕

平台已经提供本机弹幕接口。抖音的官方互动能力需要申请；获得可用事件来源后，由适配程序把昵称和消息转发到下面的接口。当前没有内置网页抓取器。

curl -X POST http://127.0.0.1:28900/api/danmaku \
  -H 'Content-Type: application/json' \
  -d '{"user":"观众A","text":"你好呀","source":"douyin"}'

输入会经过同样的过滤与排队。在“设置 → 开播准备”可查看最近一次外部弹幕来源。

6. 启动、停止和备份

以后双击项目里的“启动平台.command”。关闭浏览器不会停止后台服务；使用“停止平台.command”关闭本机平台。

备份 assets/、personas/、.state/、config.json 和 actions.json。密钥在 .secrets/，请单独保管。服务器日志在 logs/server.log。
